# EasyOra website

Static, responsive company website using the supplied EasyOra ribbon logo. The deployable site is in `dist/`. No dependencies or build step are required to serve it.

## Preview

Run `python -m http.server 4173 --directory dist` and visit `http://localhost:4173`.

## Editing

Page content and shared markup are generated by `build.py` (Python standard library). Run `python build.py` after editing it. Shared styling and interactions live in `dist/assets/style.css` and `dist/assets/main.js`.

`fonts.py` downloads the Latin variable fonts from Google Fonts for local serving; it is only needed to refresh the bundled assets. Inter and Manrope are distributed under the SIL Open Font License; see the bundled license files.

## Verification

With the local server running, run `python check.py` and `node check-interactions.cjs`. Browser visual verification is a separate manual step.

## Enquiries and privacy

The contact form generates a project brief and copies it to the clipboard, with a selectable-text fallback. It does not send or persist entries. No public email address or WhatsApp number has been supplied, so direct contact links are omitted. All portfolio work is explicitly illustrative.

## Hosting

### Vercel

Import `https://github.com/parthibanabhilash-dotcom/easyora` into Vercel. Keep the repository root as the Root Directory. The checked-in `vercel.json` selects the Other framework preset, skips build and install commands, and serves the committed `dist/` directory. Deploy the `main` branch. No environment variables are required.

The project brief remains browser-only on Vercel. Vercel access protection is managed in the Vercel project settings; Sites owner-only access does not transfer to Vercel. The current metadata and privacy notice describe the Sites private preview and should be updated to the confirmed Vercel URL and access configuration before public launch.

### Sites preview

Sites owner-private deployment is configured in `.openai/hosting.json`. Private previews are marked `noindex` and block crawling. Update canonical URLs and social metadata, review privacy details, and replace those crawler restrictions when a public launch is authorized.

No accounts, CMS, analytics, tracking cookies, backend, or notification delivery are included.
