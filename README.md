# EasyOra website

Responsive company website with a private admin panel for portfolio projects, image uploads, public contact details, and logo changes. The public site is predominantly static; administration uses Vercel Node functions and private Vercel Blob storage. See [admin documentation](docs/admin.md) for architecture and security details.

Website: https://easyora.vercel.app · Admin: https://easyora.vercel.app/admin. Owner login details are delivered in the local, Git-ignored `admin-access.txt` file.

## Preview

Run `npm ci`, `python build.py`, then `npm run dev` and visit `http://127.0.0.1:4173`. Local admin functionality requires development environment variables; it does not substitute browser storage for durable storage.

## Editing

Page content and shared markup are generated by `build.py` (Python standard library). The custom homepage scene lives in `components/hero.html`. Run `python build.py` after editing page content or assets: the generator adds content hashes to asset URLs to keep long-lived Vercel caches fresh. The live canonical origin is `https://easyora.vercel.app`.

Shared baseline styles and interactions live in `dist/assets/style.css` and `dist/assets/main.js`. The studio motion layer lives in `dist/assets/studio.css` and `dist/assets/motion.js`. The current white and mint theme is in `dist/assets/light.css`.

`catalog.py` is the content source for the five service categories and the 29 supplied service items. The homepage contains a short introduction, software/platform icons, compact service cards, and a contact CTA. The Services page contains the supplied service lists. Existing development and marketing URLs remain available; long-form guide pages remain accessible at their existing URLs but are omitted from the main navigation.

Software and social-platform SVGs are served locally from `dist/assets/brands/`; source attribution and the Simple Icons license are included there. To refresh them, run `python fetch-icons.py`, then `python build.py`. Brand marks do not indicate affiliation or endorsement.

`fonts.py` downloads the Latin variable fonts from Google Fonts for local serving; it is only needed to refresh the bundled assets. Inter and Manrope are distributed under the SIL Open Font License; see the bundled license files.

## Verification

Run `npm test`, `node check-interactions.cjs`, and `node check-motion.cjs`; with the local server running, also run `python check.py`. Browser visual verification is a separate manual step.

## Design and performance

The current edition uses predominantly white backgrounds, soft mint sections, emerald accents, and a light CSS 3D cube scene with floating interface panels. Content stays concise. It has no WebGL engine, animation library, remote fonts, canvas render loop, or third-party scripts.

Continuous movement uses CSS transforms. Intersection observers pause the hero offscreen, and hidden tabs pause its animations. Pointer updates are coalesced into animation frames and are inactive on touch devices. A visible pause control, OS reduced-motion preferences, and supported browser data-saving preferences disable motion. Content remains available without JavaScript or IntersectionObserver support.

The displayed 640px WebP logo is 29,640 bytes, versus the supplied 550,976-byte PNG. The original source logo is retained in the repository. Software and platform logos are small, lazy-loaded SVGs. Exact transferred bytes and load times depend on hosting and the visitor’s connection. Asset URLs use content hashes for cache invalidation, and Vercel serves them with long-lived browser caching. Refresh asset hashes with `python build.py` after asset edits.

## Enquiries and privacy

The contact form generates a project brief and copies it to the clipboard, with a selectable-text fallback. It does not send or persist entries. No public email address or WhatsApp number has been supplied, so direct contact links are omitted. All portfolio work is explicitly illustrative.

## Hosting

### Vercel

The existing Vercel project is connected to `https://github.com/parthibanabhilash-dotcom/easyora`. Keep the repository root as the Root Directory. `vercel.json` selects the Other framework preset, installs locked Node dependencies with `npm ci`, serves the committed `dist/` directory, and deploys Node API functions. Deploy `main`. Production CMS environment variables are described in [admin documentation](docs/admin.md) and have been configured in Vercel.

The project brief remains browser-only on Vercel. Vercel access protection is managed in the Vercel project settings; Sites owner-only access does not transfer to Vercel. Metadata and the hosting notice refer to the confirmed Vercel origin. Crawler restrictions remain in place until search indexing is explicitly requested.

### Sites preview

Sites owner-private deployment is configured in `.openai/hosting.json`. Private previews are marked `noindex` and block crawling. Update canonical URLs and social metadata, review privacy details, and replace those crawler restrictions when a public launch is authorized.

The owner admin account uses a Secure, HttpOnly session cookie. No visitor accounts, analytics, advertising trackers, or automatic notification delivery are included. Project briefs remain browser-only; portfolio, contact, and logo management use the backend.
